# ركن التطور

موقع تحويل فاخر لشركة ركن التطور — خدمات منزلية متكاملة في الإمارات.

العنوان الرسمي: https://www.rukn-eltatawer.com/

## تعديل التواصل والنصوص

حدّث `js/config.js` لرقم الهاتف، رسالة واتساب، والصور.

الخدمات موجودة في `index.html` داخل `#services`.

نموذج عرض السعر يفتح واتساب بنص يتضمن الخدمة والإمارة المختارة.

## النشر

ارفع ملفات الموقع بحيث يكون `index.html` في جذر النطاق، مع مجلدات `css/` و`js/` و`images/` كما هي.
