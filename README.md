# NAQI WASH

Luxury conversion-focused website for NAQI WASH — mobile car wash in Dubai.

Canonical URL: https://naqi-wash.atwebpages.com/

## Edit contact and copy

Update `js/config.js` for WhatsApp message, phone, and image metadata.

Services are listed in `index.html` inside `#services` (search for `EDIT SERVICES`).

## Deploy

Upload the site files to AwardSpace so `index.html` is at the domain root, with `css/`, `js/`, and `images/` intact. Keep official photos as `images/naqi-1.jpg` … `images/naqi-7.jpg`.
